# 行囊匠心与侠义计数

## 当前规则

- 匠心：作品形成完成结果，且创作工法或该版本学习卡关联了至少一本已达到「习得／悟得／传习」的秘籍，自动产生一条有效记录，无需申请迁移审核。
- 侠义：作品以 COMMUNITY 范围成功发布到大会作品页，自动产生一条有效记录。无需讲解、学习者反馈或匠心审核作为前置条件。
- 每个作品项目在每个维度各记一次。关联多本秘籍、修订版本、重复保存、重复投稿均不会重复计数；不同作品分别计数。
- 尚在创作的方案、生成失败、未关联已学秘籍不会获得匠心。私密保存、投稿待检查、退回或受限不会获得侠义。

## 接入位置

普通创作进入 SEAL 阶段、图片生成完成、创作对话结果保存，以及完成作品补充学习卡时，检查匠心资格。创作对话中用于生成的文字方案不视为完成作品。

大会发表使用原有发布流程，在审核事务将作品设为 PUBLISHED 时生成侠义证据；作品可见性和记录同时提交。

记录以作品 ID 和维度生成稳定 ID，并使用作品行锁防止不同版本的并发重复发放。证据写入沿用行囊缓存失效机制。匠心、侠义的统计与成长记录列表读取同一批新规则证据，不增加修炼次数或天数。

旧迁移审核、传习讲解数据继续保留在秘籍学习历史中，用于原有秘籍阶段推进，不再列入行囊的匠心、侠义成长统计。悟性和现有累计统计时间口径保持不变。本次未批量补记历史作品，新规则在完成、关联秘籍或发布操作时生效。

## 验证

`tests/test_creation_growth.py` 覆盖作品完成时机、已学秘籍条件、多秘籍及重复保存去重、不同作品累加、用户隔离、大会发布成功/私密/退回、跨版本投稿去重、缓存更新和旧证据兼容。

创作对话集成测试验证生成草稿时匠心为 0、真实结果生成后为 1、再次生成和保存同一作品仍为 1。
