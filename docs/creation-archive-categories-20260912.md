# 创作档案分类交互

创作档案的三个荷花分别进入图文、视频、游戏小程序作品列表。标题与三个分类文字首次进入就显示；原「选择作品查看」入口及先选作品才能点击荷花的引导已移除。荷塘背景、熊猫、荷花与云雾素材继续使用原资源。

分类使用作品的 `media_type`，不读取标题或描述关键词。`ILLUSTRATION`、`COMIC`、`MIXED_MEDIA` 归入图文，`VIDEO` 归入视频。客户端预留 `TEXT`、`IMAGE`、`GAME`、`MINI_PROGRAM` 映射；未知类型不会被默认归入图文。当前没有视频与游戏小程序作品时统一显示「暂无相关作品」。

每个分类共用作品列表、所选作品操作、更多操作与历史长对话界面。作品列表沿 `next_cursor` 读取全部有效作品，保持服务端顺序并按 ID 去重。中途分页失败会显示重试，不能将部分结果当成完整列表。

继续创作恢复所选作品的原会话。更多操作提供删除确认、大会投稿、完整历史长对话。投稿复用现有大会表单与接口；审核中和已发布状态禁止重复投稿。删除仅在接口成功后移除对应作品并刷新，保留当前分类；失败则保留作品并显示错误。选中状态与详情请求按作品 ID 隔离，新的详情请求会取消旧请求。

当前图文功能需要的列表、会话恢复、历史对话、删除、投稿接口均已存在。本次未新增视频或游戏小程序编辑器。后端目前尚无游戏小程序媒体类型，未来需补充类型与对应编辑器路由；视频/游戏作品不能进入图文编辑器。
